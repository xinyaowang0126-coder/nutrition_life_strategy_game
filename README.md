# 撑过这一周

《撑过这一周》是一款以营养科普教育为核心的校园生活策略原型。玩家需要在一周内安排三餐、餐后行动和睡眠，在预算、便利、口味与学习任务的取舍中练习饮食判断。开发目标是让玩家学会看懂组成、观察饮食规律、制定可行安排并识别资料边界，同时通过策略差异、事件和反馈保持游戏趣味性；学习与乐趣均需验证。

当前版本已经形成完整的七日闭环：每顿饭可以去食堂、点外卖、逛便利店或翻宿舍存粮，不同来源拥有独立选择上限、费用、精力代价与开放时段，也可以花钱补充有限存粮。日终按实际精力、压力、已执行行动和晚间安排生成恢复记录，次日只消费一次，影响开场状态与复习收益；第2–6天还有可提前预判的事件。HUD、新日与日结提供恢复档位和按需展开的依据，饮食观察保留独立表达；结局回顾本局真实安排。

最新完成[G4A8原餐次评分生产退休](docs/process/G4A8_SCORE_RETIREMENT_2026-10-12.md)：新餐次/跳餐不生成旧quality，旧餐食评分函数删除，余力公式独立且逐行一致。425/425、38套件，9项专项/MCP、28图和510局对照通过；仅移除10,260个旧字段，其余玩法报告字段完全一致。旧记录保留，结算签名保留废弃兼容代理，正式营养输出仍待审校。下一项已确认餐次的跨日对照与L2练习；此前[G4A7日结事实](docs/process/G4A7_FACT_SUMMARY_2026-10-12.md)及[G4A6入口](docs/process/G4A6_NORMAL_RECORD_ENTRY_2026-10-12.md)保留。

## 本地测试与发布验证

项目提供统一的 PowerShell 验证入口，先导入资源与全局脚本类，再运行数据/流程测试和主场景烟测；新副本不需要预先打开编辑器。Godot 4.7 的控制台程序可通过参数传入，也可写入 `GODOT_BIN` 环境变量：

```powershell
$env:GODOT_BIN = "C:\path\to\Godot_v4.7-stable_win64_console.exe"
.\tools\verify_project.ps1
```

只运行指定测试套件时使用 `-Suite`；不存在的套件、零测试、全跳过或日志中的脚本错误会返回失败状态：

```powershell
.\tools\verify_project.ps1 -Suite meal_systems
```

修改验证工具后运行 `.\tools\test_verification_gates.ps1`。玩法策略诊断、实际截图、证据审计与本轮验证范围见[完整评估报告](docs/process/PROJECT_AUDIT_2026-10-05.md)。

发布前使用 `-ExportWeb`。脚本会导出到临时目录，检查 Web PCK 不含 MCP 开发插件、测试和旧版游戏场景，完成后清理临时文件，不会覆盖 `Play/`：

```powershell
.\tools\verify_project.ps1 -ExportWeb
```

如需保留验证后的导出文件，可指定输出目录：

```powershell
.\tools\verify_project.ps1 -ExportWeb -ExportOutput .\artifacts\web
```

CI 中执行同一脚本即可；它不下载依赖，任何测试、主场景启动、导出或发布包审计失败都会返回非零退出码。

Web 导出需要与当前 Godot 引擎版本匹配的导出模板；例如 4.7.2 引擎需要安装 4.7.2 模板，现有 4.7 或 4.7.1 模板不能算作本机已具备完整导出环境。

## 项目结构

- `life-strategy/`：Godot 4.7 游戏项目。
  - `scripts/`：运行逻辑与数据加载。
  - `scripts/systems/`：抽牌、餐食结算、营养记录、周内事件与次日状态等纯逻辑服务。
  - `scripts/ui_v2/`：当前游戏界面和七日流程控制脚本。
  - `data/cards/`：餐食来源、食物卡、行动卡、睡眠选项 XML 数据。
  - `assets/generated/`：已接入的生成美术素材。
  - `scenes/game_v2/`：当前游戏场景、卡牌组件、阶段视图和结算界面。
  - `scenes/`：启动、主菜单和游戏场景。
  - `tests/`：MCP/Godot 冒烟测试。
  - `addons/release_guard/`：项目自身的开发设置导出隔离；Godot AI更新后仍需验证。
  - `docs/plans/`：玩法、UI、文案和 Godot 架构四份后续工作方案。
- `Play/`：GitHub Pages HTML 测试包，由 Godot Web 导出生成。
- `docs/`：项目设计、流程规范、素材说明和项目概述文档。
- `tools/`：文档与素材辅助脚本。
