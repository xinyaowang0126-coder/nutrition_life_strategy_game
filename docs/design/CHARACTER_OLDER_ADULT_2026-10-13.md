# 新人物设计：周阿姨，把自己的饭也做好

日期：2026-10-13。版本：设计稿 v1.1。按本次补充要求明确老年营养、盐糖科普与角色主线目标；本文件完成设定、七日剧情、食安机制与开发拆分，尚未接入游戏。科学依据及定量表达规则见[老年营养教育依据](../education/OLDER_ADULT_NUTRITION_EVIDENCE_2026-10-13.md)，人物与故事配置按[系列场景方案](SERIES_TITLE_AND_SCENARIO_ARCHITECTURE_2026-10-13.md)承接；本篇建议故事名为“自己的舞台 · 汇演周”。

2026-10-14续接：已完成首个双故事可玩原型，当前实现与待细化内容见[实施记录](../process/SERIES_IMPLEMENTATION_2026-10-14.md)。以下保留设计时的完整方案与当时状态，不把原型工程完成等同专业或教育验收。

## 1. 人物与这一周

**周慧兰，66岁，退休职工，平时一个人住，子女在同城另住。** 熟悉菜价，会做饭，会用手机买东西；喜欢社区合唱和在阳台养葱。她有自己的朋友和安排，不需要围着子女生活。

她做番茄炒蛋和蒸鱼很拿手。家人来时会认真配菜，自己吃饭时却常说“一个人，热热昨天的就行”。省钱、怕浪费、嫌只做一人份太麻烦，比“不懂营养”更能解释她的选择。她最近觉得硬苹果和整粒坚果不好嚼，这是这个人物的具体困难，不设成所有45岁以上人的共同属性。

人物的一周主线是：**七天后参加社区合唱汇演，在有限预算下安排好三餐、排练与休息，周日登台唱完自己喜欢的歌。** 第1天为周一，第7天为周日，演出定在周日晚饭后。玩家仍扮演人物本人，直接经历买菜、做饭、处理剩菜和安排活动的取舍。晚辈通过代入理解长辈，再把理解转成可做的帮助。

采购、约饭、分装与家庭饭承接日常支线；家人可来看演出，也可有各自安排。主线让周阿姨有自己的爱好、社交和成就。教育主旨是“老年人也要吃好，营养支持有质量的日常生活”：选餐既要关注摄入和搭配，也要关注适量与安全，不能只把课程写成各种忌口。

角色选择文案：

> **周阿姨 · 66岁 · 退休生活** <br>
> 周日就要登台了，歌词还有几处没记牢。买菜、吃饭、排练，七天得安排得过来。给别人做饭认真，自己的那一份也别凑合。

开场独白：

> “周三、周五去排练，周日晚上演出。老陈约我周五练完一起吃饭。先看看家里有什么，别又买重了。”

45岁以上是本次生活情境的范围，首位人物选66岁以突出老年营养。中国营养学会2022指南将65–79岁和80岁以上分别讨论；以后增加45–64岁人物时，按在职、照护责任及具体需要重新配置，不直接套用此人物的年龄和进食困难。[中国营养学会：老年人膳食指南核心推荐](https://dg.en.cnsoc.org/article/14/6GEB1VqTTLyP960bjRU_FQ.html)

## 2. 玩家的任务和资源

保留七天、三餐、餐后安排、晚间安排、日结与周回顾。主菜单与HUD明确显示“本周目标：周日上台”，目标进度使用“排练进度”。

| 项目 | 设计 |
| --- | --- |
| 主线目标 | 在第7天晚饭后完成社区合唱汇演；第1天明示时间，玩家能为最后一天安排精力 |
| 进度表现 | 暂定排练进度0／70；记录自练和集体排练的真实完成量。70是待平衡的游戏刻度，不是医学或音乐能力标准 |
| 排练安排 | 自己练歌占1个餐后活动，暂定每日首次进度＋8、第二次＋4，最多两次；周三／周五集体排练每次＋12。每次自练暂定精力−10、集体排练−12，确认前显示全部代价 |
| 达成条件 | 走到第7天，排练进度至少70；晚饭后演出入口暂定要求精力至少25；主动确认并完成演出，扣游戏精力10且记录参与事实。阈值均待策略试玩，不代表身体状况评估 |
| 支线 | 兑现和老陈一起吃饭的约定；按实际人数买菜；按记录分装；愿意时约家人演出前一起吃饭。支线改变故事回顾，不代替主线进度 |
| 补救与取舍 | 错过集体排练可在家练歌；外出困难时可改约近处或补约。第7天早饭后、午饭后仍可补练或休息，晚饭后进入演出阶段；不能演出后补写准备记录 |
| 资源 | 余额、精力、饱腹、心情、压力、余力，继续是游戏资源 |
| 首轮预算 | 暂定¥210，加明确列出的初始存货；是待试玩的关卡参数，不代表现实推荐生活费 |
| 起步状态 | 暂定精力60、心情55、饱腹40、压力35；余力用适配后的既有资源公式计算，不抄校园初始51 |
| 信息记录 | 食物组成、确认份量、已知钠／糖、保存过程与排练分别记录；不把“食物出现过”写成“营养已经吃够” |

教学提示、查看资料和正确回答题目不发钱、不涨精力。食安问题造成的存货损失通过实际库存体现；早睡、散步和喝水不能改变食物的保存历史。

排练、休息、采购与社交争用每天有限的活动位。食物的饱腹／精力等仍使用明确的游戏效果，不能用“蛋白质每增加1克，排练就多1分”或“钠超过参考量当天精力扣10”的规则伪造生理关系。科学饮食观察独立记录，主线通关不宣布营养合格。

进度可行性示例：6次首轮自练共48，两次集体排练共24，总计72，分布在7天的21个餐后活动位内；这是时间上的可安排性检查，实际费用、食物可得性、精力及恢复平衡尚未验证。

“一起吃饭”需要安排时间并协商，不能设置“子女花钱越多，孝心越高”的指标。电话联系可以维持沟通，但不自动记为已经共同就餐。

## 3. 四种用餐来源与人物口味

| 来源 | 能做什么 | 游戏中的代价与限制 |
| --- | --- | --- |
| 家里做饭 | 从现有食材做小份家常菜；配方显示实际原料 | 采购时付款，做饭时消费食材，不能再次按整道菜重复收费；比吃现成饭更花精力 |
| 社区食堂 | 买小份主食、蛋白质来源和蔬菜；也能和熟人一起吃 | 按关卡配置开放午餐、晚餐；早餐关闭。出门费精力，各餐牌价可见 |
| 小超市 | 买鸡蛋、奶、豆制品、蔬果等补货，或买当餐可食用食品 | 受余额、购买数量与冰箱空间限制；大包装单价低，不自动等于总支出更低 |
| 冰箱与存粮 | 查看现有食材、耐储存食品和已记录保存过程的熟食 | 按份消费库存；熟食先核对保存信息，需要时再热。没有新增现金支出不表示没有保存条件 |

社区食堂关闭时，家里和小超市保留可负担的替代方案。购物和熟食取用分开，不能“点一个来源”就得到免费新食材。

口味偏好建议复用现有独立偏好系统：番茄炒蛋、蒸鱼为偏爱餐，豆腐和温热燕麦也合口味；冷沙拉不太喜欢。口味只影响心情，不改变食物健康资料。奶茶等食物无需设置年龄禁令，由人物偏好、价格和真实配方决定如何表达。

首轮新增或细化的菜单控制在六项：小米粥、蒸蛋、炖软的时蔬豆腐、少盐版本家常菜、软煮苹果、明确保存过程的熟食份。配方不同必须有独立版本或条目，不能仅改名字就声称少盐、细软或营养更好。

蒸蛋、豆腐、蒸鱼可帮助剧情讨论如何把喜欢的食物做得更易入口；不将66岁写成只能喝粥。老年课程重点采用丰富食物、动物性食物和大豆制品、共同就餐及户外活动的框架。[国家卫健委：老年人膳食指南核心推荐](https://www.nhc.gov.cn/lljks/c100158/202210/8a11962d784540d7a61ef883948f768e.shtml)

### 3.1 必做科普：吃好与适量一起讲

| 主题 | 玩家做出的具体选择 | 玩家应理解什么 |
| --- | --- | --- |
| 能量与合理搭配 | 比较只喝稀粥与粥搭配蛋、豆腐、蔬菜的实际餐盘；照常安排主食 | 老年人需要营养，不能把少吃或只吃稀粥当成所有人的养生办法；有组成不等于份量已经足够 |
| 蛋白质来源 | 按预算和口味选鱼、蛋、肉、奶或大豆制品，并观察连续几餐 | 老年饮食仍需安排适合自己的蛋白质来源；不把高价补品当作唯一办法 |
| 奶类、蔬果及多样性 | 在实际存货中选择可接受的奶类／奶制品、蔬菜水果与主食变化 | 关注不同食物提供的营养及长期模式；保持足够摄入和适宜体重，不一味追求更瘦 |
| 盐与钠 | 读咸菜和酱油的标签；做同一道菜时选择少加盐、少放高钠调味品，并记录真实用量 | 盐要把调味品和食物中的钠一起考虑，不只计算盐勺里的量 |
| 糖 | 对比明确配方的甜饮、加糖麦片与无添加糖版本；按整份算标签 | 控制添加糖；总糖、添加糖和碳水化合物不是同一指标，“老年专用”不能代替看标签 |
| 食物适口与安全 | 按咀嚼困难调整制作方式，核对剩菜保存条件 | 吃得下、做得方便和保存安全都属于吃好的条件 |

依据、数值与适用范围见[教育依据与规则](../education/OLDER_ADULT_NUTRITION_EVIDENCE_2026-10-13.md)。采用中国营养学会2022一般成人科普参照：食盐每天不超过5克；添加糖每天不超过50克，最好控制在25克以下。这些是全天参照，不是每餐额度、身体必需的糖量或角色胜利条件。[中国营养学会：少盐少油，控糖限酒](https://dg.cnsoc.org/article/04/ApX3_ozGTmSoqQaFFh5z_Q.html)

卡面显示已知事实，例如“这一份钠700毫克”“配方添加糖8克”；没有标签／配方和实际份量时，保留对应未知。日结可展开钠和添加糖的已知小计及未知项，优先提示下次可用的调整。盐糖参考线旁同时显示本日真实餐次和食物组，不以“越少越好”引导漏餐、少吃或取消蛋白质来源。

## 4. 必做机制：隔夜菜与健康风险

**必须出现“储存不当的隔夜菜有害健康”的情节，并让玩家处理它。** 正式规则根据保存过程判断，不使用“过了午夜自动有害”或“所有隔夜菜都会致癌”。及时、卫生地冷藏的备餐与常温放了一夜的剩菜需要不同处理；食安中心对隔夜预煮蔬菜的研究和建议也强调保存温度。[食物安全中心：自备餐盒](https://www.cfs.gov.hk/sc_chi/consumer_zone/packed_meals.html)

### 4.1 熟食卡要显示什么

卡面第一层只显示菜名、做好的时间、保存地点、关键状态与可执行动作。示例：

> **昨晚的青菜** <br>
> 昨晚20:00做；今早08:00仍在灶台，常温放了12小时，未冷藏。 <br>
> **应丢弃｜储存不当，有食物中毒风险。** <br>
> [处理掉] [看看原因] [换一份早餐]

另一种示例：

> **留好的豆腐** <br>
> 昨晚18:00做；19:00前分装冷藏，冰箱4℃；未再热。 <br>
> **食用前需要彻底再热。** <br>
> [取一份再热] [留在冰箱] [看看保存记录]

第一例来自开局前一晚已发生的明确故事事实，不伪装成玩家第1天做错的结果。第二例只有在相应记录真实存在时才展示，不能因为玩家点过“放冰箱”就补齐未知的时间和温度。

### 4.2 状态与动作

| 已知情况 | 游戏中的状态与处理 |
| --- | --- |
| 干净容器分小份，及时放入4℃或以下冰箱；连续冷藏，期限及再热次数合规 | 显示“食用前需再热”；只取当餐份量，彻底再热后才进入餐盘 |
| 易腐熟食在室温放了一夜，示例明确为12小时 | 显示“应丢弃”；再热或补放冰箱不能改成可食用，提供替代餐 |
| 冷藏超过采用规则的期限，或已再热后又存放准备第二次再热 | 显示“应丢弃”；不提供循环再热续期 |
| 做好时间、保存时间或冷藏情况缺失 | 显示“保存情况不清楚”；不能用闻着正常补成安全，建议丢弃并选择替代餐 |

采用香港食物安全中心的剩余食物建议作为这个教学关卡的明确规则：尽快分小份冷却并在2小时内冷藏，剩余食物尽早吃；冷藏超过3天弃掉；不反复再热。室温超过4小时的易腐熟食弃掉。2至4小时的情形只能及时食用，不能再冷藏留作下一餐。[食物安全中心：处理剩余食物](https://www.cfs.gov.hk/sc_chi/consumer_zone/safefood_all/five_keys_apply_leftovers.html)

彻底再热的展开说明采用中心温度至少75℃；对于已因不当存放而产生的部分耐热毒素，再热不能保证消除危害。[食物环境卫生署：食物卫生守则，再热食物](https://www.fehd.gov.hk/english/publications/code/allc_4.html)

首轮课堂案例用1小时入冰箱、12小时未冷藏、保存史缺失、已再热一次四种明确情况。2小时、4小时及冷藏期限的边界按所采用原文统一实现并测试，不能在不同界面各自写一套。此规则针对关卡中的易腐熟食，不自动适用于完整水果、未开封常温食品或包装另有说明的食品。

### 4.3 游戏后果与防误导

初版将不宜食用的熟食做成可处理的库存卡，不进入可确认餐盘。玩家可以查看原因、丢弃或换餐；没有答题门槛。丢弃确实减少库存、不退购买费，补餐花钱或花精力，体现省钱与安全的现实矛盾。

“再烧开”可以作为事件中的尝试选项，选择后解释为何无法挽救这份菜并返回换餐，不自动消费或结算食物。及时冷藏的备餐可在合规再热后使用，给出省时、省钱且减少浪费的可行路线。

不设计“吃一次隔夜菜必定腹泻”“一周盐吃多就血压升高”等固定医学结果，也不捏造真实发病概率。此版用明确危害提示、不可食用状态和库存代价表达风险；以后的症状剧情需要单独设计与审校。

闻气味或尝一口不能证明安全；有害水平的致病菌未必造成异常气味和味道。[食物安全中心：夏季食物安全风险提醒](https://www.cfs.gov.hk/sc_chi/press/20230530_10344.html)

### 4.4 把预防放在前一天

做完一餐后，对未食用份提供“分小份冷藏”“现在吃完”“暂放灶台”三个处置。计划留给下一餐的份量，优先在上桌前用清洁器皿分出；处置卡显示预计保存时间。选完才更新记录，不先生成一份默认安全库存。

分装和入冰箱作为用餐收尾，不额外占整段餐后活动，避免为了参与合唱而被迫放弃基本保存。保存时长跟随关卡内时间推进；看详情、关窗口或离开电脑不按现实耗时让食物变坏。放回冰箱与再热都不能清零已经发生的温度暴露。

减少浪费的主要解法是按人数买、小份做、及时分装、在期限内用完。周回顾分别列出“因保存问题弃掉的份量”和“采购／制作过量”，不能把丢弃不安全食物写成不珍惜粮食。

## 5. 七天事件与学习机会

每一天首次介绍一个主要要点。提示挂在现有新日、选餐、收尾与日结中，不连续弹百科窗口；详细知识可展开。

| 日 | 情节与人物台词 | 玩家实际做什么 | 晚辈能带走的判断 |
| --- | --- | --- | --- |
| 第1天：灶台上的隔夜菜 | “这盘是昨晚留下的。闻着还行，热热能吃吗？” | 必经处置卡明确显示开局前常温12小时。处理后从给定库存或小超市找一份买得起的早餐 | 不用气味判断；不当存放的隔夜菜有风险，不能靠烧开挽救 |
| 第2天：粥和咸菜就够了？ | “粥煮好了，就着咸菜省事。下午还得练歌。” | 在有明确配方的菜单中比较粥＋咸菜、粥＋蛋＋蔬菜等可行组合，记录实际选择；不强制唯一餐盘 | 清淡饮食仍需要合理搭配；老年人也需要吃好并安排蛋白质来源 |
| 第3天：盐勺以外的盐 | “盐放得不多，酱油和咸菜也得算？” | 首次集体排练前安排午餐；读明确标签，按食用份量计算钠；调整同一道菜的盐和酱油用量 | 调味品、腌制品和包装食品里的钠也算；学会用已知份量比较 |
| 第4天：老年麦片也要看配料 | “写着老年营养，怎么还得看里面加了什么？” | 比较模拟麦片／饮料标签与明确配方，计算整份糖；对缺失的添加糖数量保留未知，比较蛋白质等其他已知资料 | 控添加糖、看整份；不把总糖都当添加糖，也不为控糖取消主食、奶类或水果 |
| 第5天：练完一起吃饭 | “苹果切小点就好。老陈说排练后一起吃个小份。” | 第二次集体排练与约饭；按真实进食困难改变制作方式，选择适口的蒸蛋、豆腐等可得食物 | 共同进餐与适口制作帮助实际用餐，照顾要了解喜好与困难 |
| 第6天：雨天备餐与最后一次练习 | “明天要演出，今天少跑一趟，顺便把饭留好。” | 用已有库存及近处餐点安排；按人数、预计用餐时间买小份或分装；在自练、采购和休息之间取舍 | 计划要同时考虑费用、食物多样与保存条件；不靠吃不安全剩菜省钱 |
| 第7天：上台唱自己的歌 | “饭先吃好，晚上该我们上台了。” | 根据实际排练进度和精力选择演前补练或休息；晚饭后确认参演；用实际记录完成周回顾 | 营养安排、休息和活动共同支持日常生活；游戏参演成功不证明现实营养达标 |

第2天关于清淡饮食的要点采用“减少油、盐、糖，并不等于只喝粥或不吃动物性食物”的澄清，不对单顿粥作疾病判断。[国家卫健委：2023年11月24日新闻发布会](https://www.nhc.gov.cn/xcs/c100122/202311/884f430673e54c2e8f85c0efed7347cb.shtml)

第3天的钠计算和第4天的糖计算只使用已给定的教学标签／配方，详细依据可展开。第5天围绕人物自述的咀嚼困难调整制作方式，不将高龄人群的全部建议套给66岁人物，也不在游戏中诊断吞咽障碍。营养补充品比较可作为第4天的可选延伸，不宣称全部无用；是否需要补充取决于个人情况，普通日常饮食比较不能代替专业评估。

事件发出前核对余额、来源开放、可用菜单与库存，至少保留一种合法的替代餐。核心隔夜菜场景由关卡保证出现；后续食物举例必须来自当前实际选项，不保证随机抽到某张卡。周五约饭及其补约只能用真实记录，不能在第6天假定玩家没去。

## 6. 一个完整的分支示例

第6天，商店有小包豆腐¥3、大包豆腐¥5两种规格，大包供两餐，小包供一餐；价格和份量是演示关卡数据。玩家当天只需要一餐。

| 选择 | 当下结果 | 下一次用餐时的结果 |
| --- | --- | --- |
| 买小包，做一餐 | 支出¥3，用完一份，没有熟食存货 | 下一餐重新选来源，保留现金和正常库存事实 |
| 买大包，做两餐，上桌前分出一份并及时冷藏 | 支出¥5；当餐一份，另一份记录容器、时间和冷藏情况 | 在期限内取一份彻底再热；不再次扣原食材费，可补配其他食物 |
| 买大包，整锅放在灶台过夜 | 支出¥5；当餐一份，剩下一份保存过程不合规 | 显示已在室温超过4小时，应丢弃；换餐仍需预算或合法存货 |

这三个结果表达不同的采购和保存安排。游戏不会把“小包必好、大包必坏”写成答案，也不会把第二行正常备餐和第三行危险剩菜混为一种隔夜状态。

短台词保留人物态度：

- 发现不能再热挽救：“舍不得这盘菜是真的。以后少做点，今天换一份。”
- 正确分装后：“明天那份先装好了，就不用整锅热来热去。”
- 获得具体帮助：“你帮我把苹果切小就行，我自己能吃。”
- 和邻居吃饭：“老陈说今天鱼不错。买个小份，我们各尝一点。”

## 7. 美术与界面

延续现有纸张、手绘食物、暖色生活场景。人物短发夹少量灰白，穿针织开衫，站姿自然；买菜布袋、合唱谱夹、眼镜作为日常道具。眼镜不是每张画面必带，也不以弯腰、枯瘦、拄拐表达年龄。

场景从校园换成厨房、冰箱门、小超市、社区食堂与雨天家中；增加排练室和周日晚的社区舞台。冰箱便签写“周三排练”“周日19点演出”“豆腐：昨晚19点放好”，帮助读懂真实计划。家庭饭画面给人物本人留清楚的一份，也可出现朋友共同进餐。

保留现有角色状态插画的结构，另做放松、忙碌、疲惫、陪伴四种适配表情。用餐来源是对应场景道具，不能留下食堂校园窗、宿舍门或复习台灯混用。

涉及保存状态，文字、图标、颜色一起使用；“应丢弃”不能只靠红色。关键事实和处置按钮在竖屏首层可见，不要求悬浮；菜单预览与处置确认分开，查看不会扣钱、弃掉食物或推进阶段。

## 8. 结局与周回顾

先依据游戏资源、实际排练及参演事实生成结局，再给食安、餐次、采购和社交记录各写一段短回顾。科学饮食记录可展开已知钠与糖，保留未知和份量缺口。通关不等于营养合格，点击建议也不等于已经学会。

| 结局 | 条件方向与文字 |
| --- | --- |
| **把歌唱完了** | 达到排练条件并实际完成汇演，资源维持到结局。“轮到我们的时候，歌词没忘。谢幕后，再和老陈坐一会儿。”后半句只在实际发生对应社交时使用 |
| **这次没赶上舞台** | 完成七天但排练未达条件、演前精力不足或没有实际参演。照实解释进度、当时资源与选择，不归因为不重视健康 |
| **忙了一周，先缓一缓** | 精力或余力导致提前结束。“先歇一会儿。看看哪件事能请人搭把手，哪顿饭可以换个省事的办法。”回顾只到结束日 |

记录样例“周二和周四早餐都是粥配咸菜”“这份豆腐按记录冷藏后再热一次”“两份菜因保存问题弃掉”，均须来自真实记录。不得凭结局编写“血压下降”“肌肉增强”“少了两公斤”或子女到访等未发生结果。

家庭饭是否成功、个人喜好是否出现、共同就餐次数都可以作故事回顾，不能组成孝心分、健康排名或唯一正确的家庭关系模型。

## 9. 晚辈有没有学会：试玩迁移任务

教育验证沿用现有L1组成、L2规律、L3可行安排、L4信息边界，再加入食安判断。以下是游戏外的短任务，不作为正常通关的答题关。

| 要验证的能力 | 换一道菜的任务 | 判定学会的证据 |
| --- | --- | --- |
| 保存判断 | A：青菜常温12小时／豆腐1小时内冷藏；B：米饭常温12小时／蒸蛋1小时内冷藏 | 区分应弃的食物与可按条件再热的食物，说出关键保存依据；不能全丢或全热 |
| 辨别误区 | A：“闻着正常，烧开就行？”；B：“放回冰箱就能重新计时？” | 不用气味或再热洗掉保存风险；知道需要查时间、温度和再热记录 |
| 合理搭配 | A：粥＋咸菜；B：面条＋酱菜，给出同预算可用菜单 | 提出含适合人物的蛋白质来源等具体调整，并明确没有份量与全天记录不能断言吃够 |
| 现实限制 | A：¥8、豆腐库存1份、社区午餐开放；B：同等限制的另一套食品 | 安排确实买得起、取得到；说明库存和再热／制作代价，不提出不存在的菜单 |
| 盐与钠 | A：给定酱油每100毫升钠7000毫克，用了10毫升；B：另一种调味品的同难度标签 | 算出实际份量的钠，知道盐勺以外的钠也计入；只用已知项目，不把未知当零 |
| 总糖与添加糖 | A：250毫升饮料、每100毫升总糖8克，添加糖来源未写清；B：200毫升乳饮料、每100毫升总糖10克，添加糖同样未知 | 两题都能算出20克总糖，同时说明不能直接当成20克添加糖，不因此把原味奶／完整水果等一概排除 |
| 关心转成行动 | “长辈说苹果不好嚼，又觉得一个人做饭麻烦，你会先做什么？” | 先询问实际困难与偏好，再给切小／改变做法、小份采购、一起用餐等可实行帮助；不只回答买贵补品或强迫多吃 |

前后测各七项、每项0–2分，由主持人按理由与执行可行性评分，另记“所有隔夜菜都致癌”“只喝粥才适合老人”“钠和添加糖越少就越健康”“总糖全是添加糖”“通关代表健康”等关键误解。首轮每类找5–8名晚辈及中老年参与者做形成性试玩，观察是否看得懂、能复述、愿意复玩；小样本结果用于改版，不宣称教育效果已被证明。

结局页可留一个可跳过的生活问题：“家里的人通常因为什么把饭凑合过去？你能帮哪一步？”不要求用户填写家人健康信息，不发送消息或要求联系长辈。

## 10. 现有代码承接与最小开发顺序

当前主菜单直达校园场景；`GameData`提供单一初始资源和复习目标；`GameRootV2`仍使用校园背景、事件、默认偏好和复习条件。现有偏好可加载独立人物资料，但仅添加一个偏好XML无法得到新人物玩法。

新增人物前先完成系列方案中的共用故事骨架与校园适配，再通过独立人物／汇演周配置承接下列切片。复用日常流程、UI组件和已校验服务，新库存制作／再热能力独立实现，避免复制整份`GameRootV2`作为老年版本。

| 开发切片 | 具体交付 | 必须验证 |
| --- | --- | --- |
| OA-01 人物与场景配置 | 新增可选择的`zhou_huilan_66`；配置初始资源、独立偏好、来源开放、背景和台词；默认校园入口仍可选择 | 选择、开局、重开保持人物身份；切换人物不串库存、偏好、历史和事件 |
| OA-02 任务与周内事件 | 从复习专属条件拆出通用目标接口；排练进度、每日次数、集体排练和实际参演记录及人物结局 | 人物目标类型为排练；行动、HUD、日结、新日和结局使用同一人物配置；集体排练、演出及结算不能重复完成 |
| OA-03 库存与食安 | 原料和熟食份分开；新增独立保存规则服务和收尾处置；首日固定隔夜菜事件 | 常温12小时不可食用；已不合规食物再热／冷藏不放行；1小时冷藏份可合规再热；重复确认只消费一次；未知不默认安全 |
| OA-04 家常菜单与教育表达 | 六项菜单／配方资料、教学标签、钠／总糖／添加糖字段、保存事实显示、简短反馈与周回顾；接到已有冻结餐次记录 | 份量与单位换算正确；未知不当零、总糖不冒充添加糖；角色口味、游戏数值、营养资料和食安事实分离；弃掉不算吃过 |
| OA-05 美术和试玩 | 人物立绘、家庭与社区场景、竖屏适配；执行迁移任务并修订 | 实际桌面／竖屏阅读和处置操作；省钱、正常备餐、社区就餐及雨天路线均能走完；知识误解有记录 |

食安记录至少保存：批次ID、食物／配方版本、制作时间、数量、容器及污染保护信息、入冷藏时间、温度与中断记录、危险温度累计时长、再热次数、处置及其规则版本。历史快照保持冻结，修改规则不倒改过去的记录。

先完成首日隔夜菜→合法替代早餐→正确分装→次日再热的贯通切片，以及一组有明确教学标签的钠／糖比较，再扩展七日排练与汇演主线。生产食物资料目前仍有待审校项；新配方和玩家营养文案按已有资料与文案审核流程承接。公开资料核对不等于已取得专业签署。

本轮仅交付设计稿与文档入口。人物接入、数值平衡、专业审校和真人试玩分别记进度，不能引用现有校园测试成绩当作新人物已通过验证。
