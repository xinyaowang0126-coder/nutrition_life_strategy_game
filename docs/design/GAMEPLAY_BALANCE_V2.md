## 7. 余力、日终与结局

余力基础分 = 精神状态×30% + 精力×25% + 饱腹×20% + 复习×10% + 预算安全×5% + 恢复档位贡献。

精神状态 = 心情×55% +（100−压力）×45%；恢复贡献仍为10／7／4／1。预算安全按剩余天数每天¥18计算；低于每天¥10的预留另扣8余力。低精力<16、低心情<16、高压力>88仍各扣10；饱腹<20扣10，饱腹<5再扣15。因此饱腹归零时，即使其他状态全满，余力也最多55。

日终饱腹<20额外精力−8、压力+8、心情−5；余额少于剩余天数×¥14时压力+5、心情−2；复习落后参考进度时压力+3，跟上时心情+2。按R2冻结恢复后，只在下一日开场消费一次。

餐盘类别组合只保留事实标记，取消精力+5／心情+3；旧饮食评分不再添加状态，也不参与余力。两餐合口味的额外心情由+4降为+2。三餐分别补充至少20饱腹且合计不超过¥18时，压力−2；不能用三杯咖啡触发省钱奖励。

结局边界保留：复习≥70且余力≥60为“稳稳到了周末”；余力≥25、复习≥50可为“总算到了周末”；复习<50为“这次没赶上”；余力过低触发“先歇一会儿”。连续两日余力≤15会提前结束。因此完成70仍是本周目标，50–69的阶段成果可以保留为普通结局。
