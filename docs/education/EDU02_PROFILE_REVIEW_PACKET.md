# EDU-02：首批八份资料与文案审校包

版本1.0，2026-10-08。状态：**选题、生产资料快照和文案草稿已准备；专业审校未完成，玩家营养输出未开放。** 面向成年校园生活情境的课程假设，承接[EDU-01](EDU01_LEARNING_SCENARIOS_AND_ASSESSMENT.md)。不由游戏角色年龄推定真实摄入目标。

## 1. 先做哪些内容

首批选择白米饭、鸡蛋、西红柿炒鸡蛋、鸡肉时蔬饭、苹果、原味酸奶、全麦面包、奶茶。它们覆盖单品与复合餐、两种相同原料身份、包装名称与配方的差别、未知份量，以及四来源的真实限制。

选择八份是为了形成小范围教学闭环。其余十五份继续正常参与玩法，资料不足时明确说明；不控制抽牌让玩家必须碰到某张代表卡。

当前八份均为draft：五份固定游戏规格、三份保守品类资料。固定配方可以追溯游戏物品，肯定性营养观察仍须相应外部依据、规则与专业复核。[生产快照](EDU02_PROFILE_SNAPSHOT_2026-10-08.json)保存原XML及来源哈希，不修改生产资料。

以下全部是**待审草稿**，不接入现有玩家输出。短句只说明这个游戏物品和这次记录，解释与调整分开审。

## 4. 本次来源核对

2026-10-08核对下列公开来源。一般教学框架属于来源；八项模拟配方、规则映射和草稿属于本项目，须分别审核。

- 多样与搭配：原登记准则一页面直读超时；从[中国营养学会2022核心工具包](https://www.cnsoc.org/activitykit2/6522002010.html)核对相应主题。它关注一段时间内的饮食安排，不是本项目“每餐凑齐就满分”的规则。
- 类别观察：原登记准则三页面直读超时；[中国营养学会准则三](https://www.cnsoc.org/yyzvideo/552200206.html)支持蔬果、奶类、全谷与大豆的一般课程框架。当前切片不计算个人推荐摄入量。
- 餐次与安排：[中国居民膳食指南准则六](https://dg.cnsoc.org/article/04/wDCyy7cWSJCN6pwKHOo5Dw.html)直读超时，官方检索结果提供正文；用于准备餐次课程，不将次数直接换成健康分。
- 范围交叉核对：[WHO Healthy diet](https://www.who.int/news-room/fact-sheets/detail/healthy-diet)，页面日期2026-01-26，强调饮食的适量、平衡、节制和多样，具体安排受个体、文化与可获得食物影响。
- 版本观察：[中国居民膳食指南官网](https://dg.cnsoc.org/)仍展示2022准则及2026修订工作消息。本次不据此推定未来版本发布日期，也不改变五项CDG登记的2026-10-15复核日。

公开页面核对只为审校包补充材料，不等于专业签署，不更新生产登记的accessed_at、状态或到期日。当前也没有取得适用的糖/钠分级模型，草稿high不能直接发布。
