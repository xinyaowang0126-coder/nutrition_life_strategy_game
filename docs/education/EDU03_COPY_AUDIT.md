| 咖啡描述 | 从游戏精力/压力推断困意和心跳变化 | 改为扣杯盖、带回桌边的动作 | 咖啡因原始值、时机和健康解释属于后续独立审校 |
| 鸡蛋描述 | “补上”容易暗示缺口已补齐 | 改为放到餐盘边的生活动作 | 当前鸡蛋个数/做法仍unknown |
| 卡牌分类 | 燕麦份量/形态未定却称全谷物；沙拉配方无水果却写蔬果；包装名称带营养光环 | 燕麦显示主食、面包显示面包、沙拉显示沙拉、奶茶显示饮品 | 不改物品名/玩法标签/配方，不据此替代G4审核后的组成映射 |

| 详情说明 | 每张卡重复长句，生活描述被挤到说明后 | 保留“游戏即时效果”标题；状态/帮助处提供边界；睡眠只补一条实际判断时点 | 不删除unknown/错误态，不隐藏关键规则 |
| 恢复依据 | “覆盖条件”“限幅”“明确默认状态”等开发口吻 | 改为实际精力/压力、收工时、数值上下限；保留完整可追溯数值 | 历史只读、不重算、重复打开不应用效果 |
| 结局回顾 | 零项机械罗列；“其中跳过”把跳餐误当已吃餐次的子集 | 只回顾实际出现的晚间安排，跳餐用“另外”说明 | 不虚构睡眠、考试成绩、健康改善或完整七日经历 |
| V1兼容日结 | 玩家看到“旧版加成/常规/减益档”，并由quality直接挑计划提示 | 改为记录与资料边界；提示基于实际跳餐/玩法状态 | V1不加入Web包；权重与恢复阈值保持 |

## 3. 来源与接口缺口

- 23份profile仍draft，五份首批固定规格不等于营养专业通过。见[EDU-02审校包](EDU02_PROFILE_REVIEW_PACKET.md)。当前不从旧食品类别、游戏数值或插画反推营养。
- PRODUCT-RECIPE-PENDING、CDC-SLEEP仍需复核，原2026-08-15期限保留；旧资料队列2026-09-18跟进已过。当前恢复是玩法规则，不用CDC页面替代营养资料审校。
- 五项CDG来源原复核日为2026-10-15。本次官方网页/检索核对记录在EDU-02，不更新生产日期或专业状态。
- Nutrient/limit统计、plate_quality、日终quality效果和旧组别组合仍在内部兼容路径。玩家文字已收窄，但正式替换这些接口仍须NUT-301/302/306/307/308；本轮不将NUT-308标完成。
- G4的unknown须落实到具体字段。已知组成、未知份量、未审健康解释分别处理；不给“资料不足=不好/没有”的默认结论。当前日结只做选餐事实，不宣称营养教育候选已完成。

## 4. 下一切片的文案要求

按[玩家文案准则](PLAYER_COPY_RULES.md)实现受控文案ID、变量和资料要求；与一条真实观察、实际记录、可执行替换或明确下一餐计划一起验证。四来源共用判断逻辑、保留各自的生活场景，不因当前缺蔬菜选择就批评玩家。

正式展示前逐条回填专业意见。之后用目标玩家复述“这里知道什么、还不知道什么、接下来实际能做什么”，核对学习与趣味。截图和自动测试只证明工程与布局，没有代替这两项验证。
