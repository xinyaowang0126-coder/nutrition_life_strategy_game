# 玩家文案准则

版本1.1，2026-10-08。用户进一步明确“AI感太重，尽量像一个游戏正常会有的文案风格”。高频文字以菜单、动作与日记为准：直接列配料，不每次总结或教育；数量/未知标签与解释分层。营养内容仍须证据与专业复核。[G4A2](../process/G4A2_PREVIEW_AND_GAME_COPY_2026-10-08.md)记录本轮实现，以下较早例子保留演进。

## 写给谁，写在什么地方

文字像考试周里翻菜单、算零钱、看闹钟时想到的话。用具体食物、动作、费用和记录；游戏状态说明仍要让人知道下一步能做什么。

卡面用一句生活描述；价格、库存和即时效果另列。点击详情再看规则依据。日结第一层只写这次发生了什么，营养观察最多一条；没有支持的观察就留空。结局回顾实际经历，不替玩家评价生活方式。

## 每次改字都要核对的事

1. **能由记录证明。** “吃了两餐”和“跳过一餐”分别计数；两次合口味不一定连续。没有保存份量时不写吃够，没有真实轨迹时不编熬夜和漏餐。
2. **先把信息写清，再写感受。** 用“份量还没写清”，少用“数据不完整”；用“数值到顶或到底”，少用“限幅”。版本不支持等失败原因可以直接说明，普通流程不堆schema、模型、草稿、验证等开发词。
3. **游戏数值有自己的标题。** 统一“游戏即时效果”“当前游戏数值”。不把精力、心情、余力或组合奖励写成营养作用；不在每张卡下面重复长说明。
4. **不替玩家下结论。** 不分“好食物/坏食物”，不说“吃这个就补齐”“喝咖啡心跳必然加快”“这样选就能通过考试”。建议说明可用选项和代价，让玩家决定。
5. **未知说清哪里未知。** “添加糖含量未记录”与“没有添加糖”不同；“全麦”“半糖”“原味”等名称不能代替配方或标签。只缺份量时不能把已知组成也写成全都不知道。
6. **提示对得上时间。** 当餐能执行才写“这餐可以”；需要重新看来源/预算时写“下一餐再看看”；第7日和提前结束不预告本局不会发生的效果。
7. **短句不省掉关键边界。** 首层一条提示尽量两行内，详细依据再展开。长句拆开，减少“先把这件事记下来”“根据上述条件”等无行动价值的话。准确性优先于硬凑字数。
8. **保留生活气息。** 味道、餐盘、纸袋、台灯、杯盖都可以写；幽默来自处境。少用感叹号、励志结语和网络梗，不把疲惫或预算困难写成自律失败。
9. **别替玩家复盘情绪。** 少用“留出调整空间”“先把这件事记下来”“继续按自己的节奏”等可套在任何场景的句子。没有具体事项就留空；“午饭没吃”可以只写到这里。
10. **把知识放在需要的位置。** 选餐时用配料名和未知标签；份量解释、游戏与现实边界可展开。避免每张卡、每餐和每页重复同一句说明。

## 当前用词与待开放用词

| 用途 | 当前写法 | 使用边界 |
| --- | --- | --- |
| 一周周转 | 余力 | 游戏指标，不叫健康分、恢复分 |
| 四档恢复 | 恢复充分、状态照常、有些疲惫、需要缓缓 | 与冻结记录相符；第一日叫起步状态 |
| 饮食现状 | 选餐记录、吃了几餐、选过哪些食物 | 先保留真实事实；不从旧标签推断营养 |
| 缺少信息 | 份量还没写清、配料还待核对 | 具体缺口由资料状态决定，不默认安全/有害 |
| 组成与营养观察 | 等相应资料、规则和文案审校后逐项开放 | 使用获批的文案ID与数据要求，不从卡名/插画补结论 |
| 普通按钮 | 查看、换一家、就吃这些、进入今天 | 动词指向实际操作；关闭详情不确认食物 |

## 校对样例

| 原句的问题 | 当前改法 |
| --- | --- |
| “加一个，刚好补上。”未说明补什么 | “先放到餐盘边上。” |
| “困意压下去了，心跳也快一点。”替玩家断言生理结果 | “扣好杯盖，带回桌边。” |
| “早点睡没有覆盖上述条件。”像规则文档 | “虽然早点睡了，收工时仍有这些情况。” |
| “本局记录了……晚间复习0次。”机械列零项 | 只回顾实际出现的安排；跳餐另计，不说“其中” |
| “今天几张卡带着高钠……”把旧标签当审校结果 | 先列实际食物；营养资料未核对时说明具体边界 |

静态校对不代替真人复述测试。开放科普切片后，用EDU-01的任务检查玩家理解，并记录是否因文字太多而影响选择和复玩。
