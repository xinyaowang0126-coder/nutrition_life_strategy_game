# 周阿姨第2–4天：学习切片审校包

日期：2026-10-28。状态：**工程实现与验证中的教育切片，专业审校和真人迁移验证待完成。** 本文列明给定配方、计算与玩家措辞的边界，不代表已经取得专业签署，也不开放正式健康指导开关。

## 内容与采用范围

| 切片 | 玩家能确认什么 | 保留的未知与限制 |
| --- | --- | --- |
| 第2天组成 | 从本关已选食物和声明配方看谷薯、蛋、豆制品、蔬菜等组成；可按真实手牌、余额和库存继续调整 | 缺少份量与全天安排时，不判定吃够；不从心情、价格、菜名数量推断营养充足或原料种类 |
| 第3天调味钠 | 给定酱油标签为7000毫克钠/100毫升；盐按每克400毫克钠换算。当前每人份盐/酱油追加调味量用于出题，0、750、1500毫克均只是本关配方的已记录小计 | 食材本底和未记录调味仍未知；不把小计当整餐或全天，不代表所有酱油产品，不据此诊断或更改人物健康 |
| 第4天白糖 | 当前配方每人份明确另加0/4/8克白糖，只有这部分得到确认；再热读取原批次配方 | 没有额外加白糖不等于没有总糖，其他未记录添加糖不能默认为零 |
| 标签变式A | 模拟饮料250毫升，每100毫升总糖8克，整瓶20克总糖 | 糖来源未给，添加糖量未知；此饮料不是玩家餐盘中的食物 |
| 标签变式B | 模拟饮料300毫升，每100毫升总糖6克，整瓶18克总糖 | 同上；变式不替换真实配方，不写进餐次或日结摄入 |
| 外食与存粮 | 外食没有调味记录则保留未知；熟食有冻结配方则读取原记录；常温奶/完整水果没有配方时不补造调味量 | 混合取用的未记录项目明确显示，不把已知的一部分扩展到整餐 |

盐钠的标签变式另给7000毫克/100毫升×10毫升，以及6000毫克/100毫升×5毫升，分别得到700和300毫克。它们是独立教学题，不改变实际配方所用的标签或盐/酱油用量。

## 学习记录与验收口径

- 预览、已确认餐次和纯教学变式分别标明。只有确认进餐才保存餐次事实；关闭练习或取消配方不会生成已吃记录。
- 每个真实情境及变式保留首次选择、是否先看解释/依据、重试、跳过与查看次数。读取存档恢复当前题面或反馈，不增加查看/作答次数。
- 正确重试不覆盖首次错误。看过帮助后的首次作答单独标记，不当成独立判断证据。
- 单个情境保留首次及最近31次作答，累计次数独立；变式采用不同数值和明确来源，不能将重复作答次数算成学习人数。
- 日结观察只取已确认餐次；无配方记录时数值保持未知，不显示零摄入或营养好评。观察和下一次操作提示冻结进当日历史。
- 游戏通关、打开练习或一次答对均不证明已经学会。真人验证需换菜单、换标签，并记录理由、前后表现和关键误解。

## 待审校项目

1. 食物组成的分类、缺少份量时的解释与可行调整提示，是否适合本篇的晚辈和中老年参与者。
2. 当前调味量与“每人份已知小计”的表述是否足够清楚；混合未知项目是否会被误认为已经补齐。
3. 总糖、添加糖、另加白糖及其他未知糖来源的区别，是否能在短句和变式中正确理解。
4. 标签练习是否过度依赖记忆答案，能否迁移到新标签；解释与重试是否影响正常游玩节奏。
