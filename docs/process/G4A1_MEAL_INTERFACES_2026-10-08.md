# G4A1：单餐组成与受控文案独立模块

2026-10-08，承接EDU-02/03。完成本地独立工程切片，生产界面及营养输出未开放。[接口契约](../design/G4A1_MEAL_COMPOSITION_CONTRACT.md)规定本切片范围。

## 本轮实现

- HealthGuidanceConfig：版本化的食物组→结构角色、置信度/贡献语义与默认draft审核状态；水果、奶类、坚果、饮品分开记录。
- DietPatternEvaluator：复用已冻结MealHealthSnapshot，保留实际进餐/跳餐/旧历史状态，按ingredient_id去重并保留来源。已知组成和未知份量分开，资料不全保留窄的已知线索，不把unknown当没有。另一道菜的trace不覆盖原先有效material；加入可靠线索和变换选择顺序的边界通过。
- GuidanceComposer与guidance_copy.xml：六个受控ID，一条短句；正向模板仍draft。变量只允许由有效类别构造的文字，模板/元数据/证据能力重新检查；中性模板不能改名绕审核。
- 配置/profile/文案分别检查审核者、日期与引用能力；过期/待复核/被替代/缺失不能放行，配方依据不能单独代替PLAYER_GUIDANCE。日/周聚合和因素规则明确not_evaluated，建议null，不补造健康结论。
- tests/fixtures/g4_meal的来源、profiles与审核信息全部是隔离测试元数据。测试路径不打包、不更新生产登记，也不代表营养专业审校。
