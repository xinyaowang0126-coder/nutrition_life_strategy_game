# 选中色与选餐布局统一

选中卡牌恢复暖金色卡面，食堂、便利店、宿舍和外卖使用同样的选中染色；移出后恢复普通卡色，详情与选择操作保持原有方式。

四个选餐页共用 `MealStageBaseV2` 的卡牌区、已选区和底部按钮位置。桌面与竖屏均为上方选卡、下方偏右显示已选食物。外卖保留列表式卡片与上下滚动，新增购物袋预览，确认按钮移至统一底栏。宿舍卡牌区在桌面展开，竖屏保留两列滚动；按当前选择上限显示可用餐盘格数。餐后安排与夜间提示也对齐下方区域。

验证包括选中后刷新可用状态、取消选中恢复颜色的回归检查，以及四来源在1920×1080、1366×768、390×844的12组原生渲染与鼠标输入检查。检查共享区域、无遮挡确认、悬停详情、卡面点击及选中色。属于 Windows 窗口检查，不代表实体手机测试。
