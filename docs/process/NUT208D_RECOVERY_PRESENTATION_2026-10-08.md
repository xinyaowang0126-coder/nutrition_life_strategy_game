# NUT-208D：恢复依据与真实轨迹表达

日期：2026-10-08。承接C1–C3，完成恢复轨道的玩家表达及联合本地工程验收。项目仍以营养科普教育为主要目的，恢复只用于解释游戏决策。

## 已实现的玩家变化

- V2 HUD以文字展示“昨夜恢复”四档；第一日明确“起步状态”。移除旧数字控件，未知历史、非法与未来记录有独立文字，不默认正常恢复。
- 新RecoveryPresenter只读取冻结记录，不重新判定历史或改变数值。状态详情与新日“查看恢复依据”说明命中原因、实际晚间安排、睡前→安排后→日终精力/压力、其他有序日终效果与限幅。首层最多两条主要依据，完整依据可滚动查看。
- 详情区分当前绝对数值与卡牌即时增量，四来源/食物/行动/睡眠都明确即时数值是游戏效果。睡眠详情不提前承诺恢复档位；复习详情保留恢复、事件及临时精力/压力的来源说明。
- 日结并列饮食观察、今晚恢复依据与明天效果；饮食数据不写入恢复模块。第7日说明次日效果未在本局应用。本周轨迹读取冻结恢复记录，结局按实际日数、进餐、跳餐、早睡和晚间复习生成，不虚构漏餐、熬夜、交卷、成绩或健康结果。
- V1保留兼容入口，同源展示恢复/依据、滚动日结与实际经历结局；仍不加入Web发布包。
- HUD与新日绑定已消费记录的独立副本；可变展示别名不能改变文案。新日详情在模态层上方显示，打开时暂时禁用底层推进，关闭后恢复。真实输入发现并修复Esc被焦点控件接收的问题。
