# 界面操作打磨：键盘返回与焦点

后续[每日流程打磨](DAILY_UI_POLISH_2026-10-15.md)发现并修复了本轮共用工作台处理对普通来源页的影响：来源页会在新日提示后接走Enter。后续477/477、42套，以及新日／日结／详情／记录的实际键盘检查通过。下文470/470及网页检查为本轮当时的覆盖范围。

在已接入的做饭、冰箱和存档界面上，继续完善键盘操作。原生输入复现了 Esc 无法返回、确认框的 Tab 焦点进入背后页面，以及首个存档按钮禁用时无法获得初始焦点的问题。

本轮完成：

- 做饭、厨房、菜单和存档工作台支持 Esc 返回；选中的菜、原料、调味库存与餐次保持原样。
- Tab／Shift+Tab 在当前面板内循环，方向键沿用面板内的空间关系，边缘焦点不会进入背后的游戏。
- 关闭工作台后恢复打开它的按钮焦点；选菜页重建导致容器路径变化时，只恢复唯一匹配的具名控件。
- 人物入口、选菜和工作台的滚动区域跟随键盘焦点，屏外按钮可被带入可见区域。
- 确认弹窗的 Esc 只选择可用的“取消／返回／关闭”；等待保存回执时不会关闭，也不会触发背后按钮。
- 初始焦点跳过禁用位置；弹窗关闭后恢复入口焦点，旧弹窗按钮和重复返回不会再次执行选择。

涉及 [HouseholdUI](../../life-strategy/scripts/stories/HouseholdUI.gd)、[HouseholdWorktop](../../life-strategy/scripts/stories/HouseholdWorktop.gd)、[StoryDialog](../../life-strategy/scripts/stories/StoryDialog.gd) 及原有控制器；沿用本轮之前的美术和布局。
