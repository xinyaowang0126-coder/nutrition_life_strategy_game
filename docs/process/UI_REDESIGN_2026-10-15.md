# 功能界面接入原有游戏

此前周慧兰的做饭、保存、共餐等规则多依赖通用长文字弹窗。这次按用户选定的“第2套原料、第1套色彩”改为现有游戏舞台中的功能面板，人物、背景、顶部状态、七日推进与结算服务继续复用。

已改动：

- 故事入口：人物与目标并排呈现，两篇故事更容易同时看见，存档导入移到故事卡后。
- 用餐来源与选菜：家中做饭、冰箱和购买使用各自说明；已选餐食与固定操作按钮分离；详情改为主动点击。
- 做饭配方：原料插画、所需份数、库存、盐／酱油、额外白糖、当餐人数和留存选择联动预览。确认才调用原有原子扣料接口。
- 冰箱与存粮：逐批展示保存史和状态，不安全／保存史不清的熟食不能进餐盘，可单独丢弃。
- 共餐：选择地点，预先说明费用和人数，实际进餐才完成约定。
- 餐桌记录、菜单与存读档：改为卡片和摘要，保留覆盖确认、文件导入导出和原有存档格式。

共用[HouseholdWorktop](../../life-strategy/scripts/stories/HouseholdWorktop.gd)与[HouseholdUI](../../life-strategy/scripts/stories/HouseholdUI.gd)，由原有[GameRootV2](../../life-strategy/scripts/ui_v2/GameRootV2.gd)管理。工作台阻止背后的操作，关闭后恢复界面；旧按钮的延迟信号和重复点击不会重复扣料或推进。手机沿用原来的安全区域，桌面做饭页采用两栏。

原料Atlas来自内置ImageGen，精确区域映射与来源记录已保存。正文使用约339KB的静态Noto Sans SC 500子集，生成脚本为[build_household_font.py](../../tools/build_household_font.py)；新增文案时可重新生成。字库附带OFL许可，标题复用原HUD字库。

验证：完整467/467、42套测试通过；介绍布局调整后再次467/467通过，来源卡和菜卡调整后UI套件6/6通过。640×960、1280×720的原生鼠标流程、原生触摸滑动和键盘输入通过，另有三种逻辑画布的边界检查。主场景与Web资源审查通过。详细结果与范围见[verification.json](../assets/ui-redesign-2026-10-14/implementation/verification.json)。

用户明确授权本机预览后，已完成内置浏览器的桌面／手机布局、做饭预览、确认结算、刷新继续、手动存读档和原料核验。开发日志未发现错误或警告。[design-qa.md](../../design-qa.md)已更新为passed，证据包含同一输入中的全图及局部对比。来源授权问题没有通过替代浏览器或间接抓取绕过。

网页检查中另修复了人物目标断行、来源说明贴边、菜卡状态裁切、恢复后原料顺序，以及选中并悬停时文字颜色。真实手机硬件触摸、读屏、浏览器文件选择器和浏览器完整七日不在此次验收范围内。预览中保留了验收用自动进度和手动存档1，可从故事入口重新开始。
