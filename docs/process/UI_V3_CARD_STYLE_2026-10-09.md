# 卡牌视觉升级

本轮将用餐来源选择页改为手绘校园地图，更新主菜单、顶部信息栏和卡牌状态。保留选地点、选食物、确认结算的流程，以及悬停预览、固定详情、键盘操作和触屏长按。

## 画面与交互

- 主菜单使用宿舍清晨插画、暖米色纸面和原有角色，删去装饰性说明。
- 地图提供食堂、便利店、外卖与宿舍存粮四个入口。点击、悬停和规则弹窗沿用原版，未营业入口显示简短状态。
- 顶部显示日期、七天进度、时段、余额和菜单。竖屏收起进度小卡，以保留空间。
- 卡牌保留原有插画和分类边框，选中时显示“已选”与暖金色框；不可用时保留可读文字，键盘焦点描边整个卡牌。
- 餐后行动不再重复显示零现金费用的“免费”。桌面清晨、午后、傍晚场景接入新插画；夜间回到宿舍。
- 背景切换先取消未结束的动画，避免快速操作后旧回调覆盖当前背景。
